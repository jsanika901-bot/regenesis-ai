# RE:GENESIS AI 🌍♻️
**Nothing Is Waste. Everything Has a Second Life.**

RE:GENESIS AI is an AI-powered circular manufacturing and material recovery ecosystem built for **Kiroween 2026** (Frankenstein Category).

## ✨ Key Features
- **AI Material Vision Scanner:** Multimodal material classification, condition grading, and recyclability analysis powered by Google Gemini.
- **Mode 1 — Raw Material Creation Simulator:** Simulates thermal and mechanical recovery of discarded plastics, textiles, and rubber into reusable feedstock.
- **Mode 2 — AI Product Manufacturing Studio:** Generates product concepts, feasibility scores, Bills of Materials (BOM), and production workflows from live inventory.
- **Three Ecosystem Tiers:** Switchable dashboards for **RE:GENESIS HOME**, **RE:GENESIS BUSINESS**, and **RE:GENESIS GLOBAL**.
- **Spec-Driven Architecture (`.kiro`):** Built using structured specifications, steering docs, and agent hooks inside the root `/.kiro` directory.

## 🛠️ Tech Stack
React, TypeScript, Tailwind CSS, Vite, Express.js, Google Gemini API (`@google/genai`).
